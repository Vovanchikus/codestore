Сортировка

Описание: Управляет вариантами сортировки на фронтенде и поведением по умолчанию.

Логика работы
  • Если сортировка выключена — на фронте выбор сортировки скрыт и применяется сортировка по умолчанию.
  • Если включена — посетитель может выбрать доступные варианты, указанные в настройках.
  • Параметр URL ?sort= переопределяет значение по умолчанию.
Доступные Twig-флаги
  • sortingItems — массив элементов сортировки (label, href, isActive, icon)
    • +
  • catalog.sorting_enabled — включена ли сортировка
Пример Twig
{% raw %} +{% for item in sortingItems %} + {{ item.label }} +{% endfor %} +{% endraw %}
