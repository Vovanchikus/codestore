Динамические поля

Описание: Динамические поля позволяют добавлять наборы полей для материалов в каталоге без изменения кода.

Логика работы
  • Добавленные поля сохраняются в схеме каталога и доступны в данных материала.
  • Для вывода используйте `item.data.FIELD_NAME` в Twig.
Доступные Twig-флаги
  • item.data.FIELD_NAME — значение поля
  • item.getField('FIELD_NAME') — (если доступно) вспомогательный метод модели
Пример Twig
{% raw %} +{% if item.data.custom_text %} +

{{ item.data.custom_text }}

+{% endif %} +{% endraw %}
