Бейдж «Обновлён»

Описание: Функция показывает бейдж «Обновлён» в течение заданного количества дней после изменения материала.

Логика работы
  • При создании материала бейдж не показывается.
  • При редактировании материала: если отслеживаемое поле изменилось — материал считается обновлённым.
  • В течение N дней показывается бейдж; после истечения срока отображается версия материала.
Доступные Twig-флаги
  • item.is_updated — true, если материал обновлён недавно
  • item.display_version — версия для вывода
  • item.updated_days — сколько дней прошло с обновления
Пример Twig
{% raw %} {% if item.is_updated %} Обновлён {% elseif item.display_version %} Версия: {{ item.display_version }} {% endif %} {% endraw %}

Важно: логика вычислений остаётся в PHP. Twig используется только для вывода.
