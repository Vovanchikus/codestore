Флаги и опции

Описание: Флаги включают/выключают различные функции каталога, например рейтинг, комментарии и модерацию.

Логика работы
  • Каждый флаг включает соответствующий функционал в плагине (UI + логика).
  • Флаги влияют на вывод в Twig — проверяйте `catalog.feature_*` при формировании шаблонов.
Доступные Twig-флаги
  • catalog.feature_comments
    • +
  • catalog.feature_rating
    • +
  • catalog.feature_moderation
Пример Twig
{% raw %} +{% if catalog.feature_comments %} + {% include 'partials/comments' %} +{% endif %} +{% endraw %}
